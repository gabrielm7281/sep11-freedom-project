# SEP11 Freedom Project
by **X**

## Context
I am a student at [HSTAT](https://www.hstat.org/) in the [Software Engineering Program](https://hstatsep.github.io/). The "Freedom Project" for SEP11 is a year-long project all about making something using JavaScript along with a third-party JS tool.

For my project, I chose to independently study **Phaser** in order to help me make **a fighting game**. Phaser is a JS framework. It has custom code that I could use to create games. I chose it because I saw how expansive it's games were and how much I liked them. However it was very tricky to make it look like what I saw online
